# M0 — India coverage spike

Question: what share of top Indian tech employers can we reach via **legitimate** sources?
Go/no-go: **≥ 40% reachable via Tier 1–3** (see [SPEC §12](../docs/SPEC.md#12-milestones)).

## Files

| File | What |
|---|---|
| `companies.csv` | Seed list: 300 Indian tech employers — 127 well-known tech companies plus 173 mid-size firms (IT services, engineering/electronics, BFSI, product, consumer, fintech). Domains are unverified — the probe surfaces bad ones. |
| `probe.py` | Probe script (Python 3.10+, standard library only). |
| `results.csv`, `summary.md` | Generated by the probe. Commit them after a run. |

## Run it

```bash
cd m0
python3 probe.py --limit 5     # smoke test (~1 min)
python3 probe.py               # full run (~30–60 min; it is deliberately slow and polite)
```

Run it from a normal home/office connection. Don't run it through a VPN or proxy pool — that would break the ground rules.

## What it does per company

1. **Tier 1:** tries Greenhouse, Lever, Ashby, SmartRecruiters and Workable public board APIs with slug guesses (domain root, company name). Counts total jobs and jobs located in India.
2. **Tier 2 / Enterprise:** fetches `/careers`, `careers.<domain>`, `/jobs`, `jobs.<domain>` (only if `robots.txt` allows) and fingerprints the ATS (Darwinbox, Keka, Zoho Recruit, Workday, SuccessFactors, …).
3. **Tier 3:** counts schema.org `JobPosting` JSON-LD blocks on that page.

One request per host per second, honest User-Agent, no retries against blocks.

## Reading the results

- `tier=1` — ready for M1.
- `tier=2` / `tier=E` — ATS found, but **its terms must be reviewed** before we index it.
- `tier=3` — career page carries structured job data.
- `unreachable` with an `errors` column → network problem, re-run. Without errors → no source found (slug guess missed, JS-only career page, or custom site). Hand-check a sample of these: slug misses are likely false negatives.

## Known limitations

- Slug guessing misses boards with odd tokens (e.g. Greenhouse boards named after the legal entity). Fix by hand-adding `ats_slug` findings back into the list.
- JS-rendered career pages show no fingerprint in raw HTML → under-counts Tier 2/E.
- "India jobs" uses a city/country regex on location fields; approximate.
